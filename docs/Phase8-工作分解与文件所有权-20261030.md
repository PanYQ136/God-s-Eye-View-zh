## 8. 串行执行与交接

### 8.1 顺序（硬约束，不许并行）

```
B(材质/CSS/状态) ─→ C(lens GL) ─→ D(层叠+总线) ─→ E(Cesium/拆分/构建) ─→ F(Gate)
                                        ENV(非代码，随时记录，不阻塞)
```

理由链：
- B 先跑：`material.css` 是唯一材质来源，D2/D9 需要的 CSS 变量兜底必须先在 B 落地。
- C 次之：lens 是 shader/stats 唯一写者；D2/D4/D5/D9/D10 全在这一文件。
- D 再次：`@layer` 归位会改全部 CSS 的层叠语义，必须在 B/C 的视觉值定稿后做，否则视觉回归无从判断。
- E 最后改代码：codemod（Cesium 单一出口）会横扫 `src/**`，必须在 B/C/D 全部合入后跑，否则冲突率爆炸。
- F 只读：不改代码、不改阈值。
