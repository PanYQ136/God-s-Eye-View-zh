## 4. 实施约束（踩过的坑，务必写进任务）

1. **两类落点别混**：A1–A4 数据图层走正式 catalog（§1 的 8 步路径）；A5/A7 的 UI 浮层走 `src/gev-cn-*.js`，由 `src/boot-defer.js` 的 `DEFERRED` 动态装载（不是 index.html 静态 script），删掉该行即回滚。不要改 `src/app/application.js`、`src/app/viewer.js` 或 Cesium 主链；增强层只经 §3 的全局 seam 只读访问。**`DEFERRED` 是启动时立即 `import()` 的并行装载**，模块顶层不得读 `window.__godsEyeView` / `__gevViewer`（此时尚未设置）——要等就绪或放进事件回调，并做空值保护；天气与健康的首次请求也放到就绪之后，避免与首帧争带宽。
2. **坐标系（最容易出错的一条，必须按端点分别处理，不要一刀切）**：Cesium 用 WGS-84；服务端 `cn-live.js` **全文零 import/require、没有任何坐标转换**，返回的是上游原始坐标。
   - `/api/cn/traffic`：`cells[].lat/lng` 是**请求 bbox 网格点的原值**（`cn-live.js:84-85` 直接回显，高德查询也用同一值）。传 WGS-84 视口 bbox，返回点**直接按 WGS-84 画、不要再逆变换**，否则整体偏约 500 米。代价是采样点在高德侧有 ~500m 偏移；若要消除，先把 bbox 转成 GCJ-02 传入、再把返回的 cells 转回 WGS-84，两步必须成对。
   - `/api/cn/admin`：`cityBoundary.polyline` / `districts[].polyline` 是**高德原始 GCJ-02**（`:616` 直接透传）→ 逐点做 **GCJ02→WGS84** 再投 `Cartesian3`，不转整体偏约 500 米。格式见 A2 的 `parseAmapPolyline()`。
   - `/api/cn/quakes`、`/api/cn/typhoon`：CENC / 中央气象台原始经纬度是 **WGS-84**（服务端未转换、无 `crs` 标记；小程序 `utils/render.js:386` 默认按 WGS-84 处理可佐证）→ **不要转换**，直接用。
   - `/api/mini/geocode`、`/api/mini/rgeocode`：高德/腾讯是 **GCJ-02**，Nominatim / Photon / 天地图是 **WGS-84**；每条结果带 `crs`，**仅对 `crs==='gcj02'` 做逆变换**。
   小程序 `utils/render.js:386` 是「`crs==='gcj02'` 就跳过自己的 WGS84→GCJ02 转换」，因为腾讯地图本身是 GCJ-02——**本次方向相反，不要照抄**。
3. **台风解析别自己写**：`typhoon.nmc.cn` 要浏览器 UA（`cn-live.js:37`）、JSONP 是**双层括号** `name(({...}))`（`:131–137`），服务端已处理；前端只消费 JSON。

5. **中文文案进字典**：新增 UI 文本写进 `src/gev-cn-dict.js`，不要硬编码到主逻辑。
6. **图层默认关闭**：新增 A1–A4 一律默认 off，分组沿用 `src/ui/layerPanel.js` 的 `PANEL_GROUPS` 六个组：Movement / Cameras / Infrastructure / Events / Weather / Utilities。海外视角下国内图层要自动隐藏或明确显示「该区域无数据」，不得报错；A6 的新 geocoder 在非大陆查询时应**不发请求、直接返回 `{place:null, answered:true}`**（decline，让原有链继续），不要拖慢搜索链。理由见 §4-9。
