> 目的：在 Phase7A-D 已有结论之上，补「交付层与代码结构层」的体检，并指出**当前生产产物已过期**。

## 0. 一句话结论

分层（`src/lc` 七件套 + `@layer` 五层 + 边界检查脚本）已经是**同类项目里偏上水平**，不该再投入重构。
真实债务在**产物交付**与**样式覆盖链**两处，且当前 4174 服务的 `dist/` 是一个**未过产物闸门的旧构建**。

## 2. P0 缺陷：生产产物是过期且未过闸门的旧构建

- `dist/` 时间戳 **10-30 15:52**，`dist/models` 里仍是 `_norm`(146M) / `_skb`(159M) / `_baked`(37M) 三套工作副本。
- 同一天之后的三次构建（`dist-8e2` 等）都被 `build/models.mjs` 的 `pruneModels` 裁到 **3.4MB**。
- 结论：4174 当前服务的不是最新产物，且**没有**产物闸门。任何基于 4174 的验收都在测旧代码。
- 影响：部署/同步体积 380MB vs 36MB（10.6×）；模型不再被页面请求，故不直接拖慢首屏，但让「构建产物 = 可发布物」这个契约失效。
- 修法（可回滚）：`node ./node_modules/vite/bin/vite.js build` 重建 `dist/`；`GEV_KEEP_ALL_MODELS=1` 可回到全量。
- 风险：**会改掉 4174 正在服务的代码**，需在无人验收时执行。

## 3. P1 债务：Cesium 求值 3s 仍是首屏唯一物理瓶颈

- 传输侧已压到 1.70MB，`defer` + `preload` + `cesium-boot.js` 按需注入都已就位。
- 剩下的 **3.0s 是 5.73MB classic script 的解析+求值**，与网络无关，只能靠「改变加载模型」解决：
  1. 把 Cesium 改 ESM 按需 chunk（只 import 用到的 `Viewer`/`Scene`/`ImageryLayer` 等）；
  2. 或把 `Viewer` 构造挪进 Worker 前置（不可行，Cesium 依赖 DOM/WebGL）。
- 收益/风险：−1.5～2.5s 首帧前主线程块；风险中高（Cesium 的 `Workers/`、`Assets/`、`Widgets/` 路径与全局 `Cesium` 变量耦合）。
- **建议单开卡**，先做一次只读可行性探针（统计 `window.Cesium.*` 实际引用面），再决策。

## 4. P1 债务：样式覆盖链（overrides 层）

- `public/gev-fix.css` / `gev-responsive.css` / `gev-panel-win.css` / `gev-cn.css` / `gev-material-override.css` 是**补丁史**产物，命名即证据。
- 它们整体挂在 `overrides` 层，压过 `components` 与 `material`；124 处 `!important` 有一半是为了跨过这条链。
- 归并路径（低风险、可分步）：
  1. 只读产出「每条 `public/gev-*.css` 规则 → 应当归属的 components 文件」映射；
  2. 按映射迁入 `src/ui/styles/*`，每迁一个文件跑一次视觉审计清单（初始/7 卡/dock/移动端）；
  3. 迁完删空 `overrides` 层，`!important` 只留 Cesium widgets 反压所需。
- 收益：样式可预测性（不再靠 link 顺序取胜），打包后单 CSS；不改视觉。

## 5. P2：`src` 根 63 个散文件

- `src/` 根与 `src/lc|app|ui|data|layers` 并存 63 个 `.js`（`gev-*`、`hud*`、`keySetup` …），是从单体迁移到分层时的中途态。
- 不建议大迁移（197k 行、421 测试、脏工作区数十文件）。建议**只做单向约束**：新增代码一律进分层目录，根目录冻结，由边界脚本加一条「`src/*.js` 数量不得增加」的守卫。

## 6. P2：数据双份出货

- 3 组数据同时以「静态 `.json`（fetch）+ 打进 chunk 的 `.json`（离线兜底 import）」出现：
  `regions` 1.99M×2、`marine` 633K×2、`san-francisco` 222K×2，**重复约 2.8MB**。
- 兜底是 `loadBundledJson` 的离线语义，不能直接删。可选：把兜底改成「fetch 失败 → 提示离线」而不是再打一份。
